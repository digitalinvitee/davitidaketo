# Keto & Daviti Wedding Invitation — Final UI Build

Place your existing `assets` folder beside these files:

- `index.html`
- `style.css`
- `script.js`
- `assets/`

Then open `index.html` with Live Server or deploy the entire folder to GitHub Pages.

This version includes:
- refined Georgian typography and spacing;
- corrected polaroid and floral layering;
- compact invitation text rhythm;
- full-screen, distraction-free wedding details and RSVP panels;
- locked background scrolling while panels are open;
- mobile safe-area handling.
